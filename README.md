# Trabajo Practico

Aplicación de práctica en Node.js para entregar como trabajo practico de backend.
Por consola usá GET products para obtener todos los productos
Con GET products/<numero de producto> se obtiene un praoducto en particular
Usando DELETE products/<numero de producto> se borra un producto en particular
y con POST products <titulo> <precio> <categoria> se inserta un nuevo producto


## 🚀 Tecnologías utilizadas

- Node.js
- Express (en breve)
